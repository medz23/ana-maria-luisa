Projects

🏆 1st place · CLEF 2026 JOKER IROH: Humor Retrieval Pipeline

BM25 + Dense Retrieval • Cross-Encoder Reranker • LoRA/QLoRA LLM Judges

Built a three-stage humor retrieval pipeline combining hybrid sparse-dense retrieval, a finetuned cross-encoder reranker, and an ensemble of LoRA-adapted LLM judges trained on distilled rationales, ranking 1st on the official JOKER 2026 Task 1 English leaderboard with a MAP of 0.6347.

Top 29 of 114 · CLEF 2026 EXIST Multimodal Sexism Detection in Memes

CLIP + XLM-RoBERTa • FiLM Conditioning • Cross-Attention

Developed a human-centered multimodal model fusing meme text, a generated visual description, the image, annotator demographics, and physiological signals, using cross-attention to ground the description in the image and FiLM to condition on annotator context.

ACAT: Collaborative Annotation Tool for ABSA

Flask • PostgreSQL • Docker

A web-based annotation platform covering four ABSA tasks of increasing granularity, computing inter-annotator agreement (Cohen's/Fleiss' Kappa) directly at export time and exporting to CSV, JSON, and XML. Published as an arXiv preprint.

Scholar Rank: Python Exam IDE

Flask • PostgreSQL • Docker • Monaco Editor

A web-based exam platform where students solve Python problems in a browser IDE and their code is graded automatically inside sandboxed Docker containers. Includes a professor dashboard, randomized problem pools, and anti-cheat measures, and is actively used for live lab exams.

NLP with Disaster Tweets (Kaggle)

Logistic Regression • BERT • BERTTweet Large
